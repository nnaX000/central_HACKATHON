# 🌙 DREAM CATCHER - 백엔드 레포지토리

## 프로젝트 소개
**멋쟁이 사자처럼 중앙해커톤** 출품 프로젝트입니다.

'쉬었음 청년', '고립·은둔 청년’ 문제를 해결하기 위해 하루의 가장 기초적인 생활 기록부터 장기 목표까지 **드림 파트너와 함께 성장해 나갈 수 있는 자기 관리 플랫폼**입니다.

---

## 개발 기간  
**2024.07.09 ~ 2024.08.06**

---

## 주요 기능
<br>

| 기능 | 설명 |
|------|------|
| **회원가입/로그인** | JWT 기반 인증 시스템 |
| **EveryList** | 하루의 To-do 리스트 생성·조회·수정·삭제 |
| **LifeList** | 장기 목표 설정·관리 기능 |
| **드림 파트너 캐릭터 시스템** | 캐릭터 성장(먹기/운동/청소/씻기) 기능 |
| **일별 기록 조회** | 하루 단위의 활동/식사/일기/운동 등을 묶어 조회 |
| **추천 기능** | 키워드 기반·랜덤 추천으로 새로운 목표 제안 |
| **게시판 기능** | 게시글 작성, 수정, 삭제, 좋아요, 신고 기능 |
| **알림 기능** | 활동·게시물 관련 알림 조회 및 읽음 처리 |

# 💡 담당한 개발 내용
<br>

> **회원 기능부터 캐릭터 시스템, 추천 기능, 일기, 그리고 서버 배포** 같은 백엔드 기능을 전반적으로 구현했습니다.
<br><br>

## 1. 사용자 기능 개발
- 회원가입
- 로그인
- 아이디 중복 확인
- 계정 삭제
- 로그아웃
- 프로필 사진 수정
- 개인정보 수정
- 사용자 정보 조회
- 비밀번호 재설정을 위한 이메일 요청
- 비밀번호 재설정 확인
<br><br>

## 2. 캐릭터 시스템 개발
- 캐릭터 생성
- 캐릭터 정보 조회
- 캐릭터 타입 변경
- 캐릭터 행동 기록
- 캐릭터 게이지 조회
- 캐릭터 비활성화
- 캐릭터 엔딩 조회
- 캐릭터 행동에 따른 게이지 업데이트
<br><br>

## 3. 추천 기능 개발
- 랜덤 음식 키워드 추천
- 사용자 입력 기반 음식 키워드 추천
<br><br>

## 4. 일기 기능 개발
- 일기 작성 기능 구현
<br><br>

## 5. 서버 및 배포
- AWS EC2 서버 배포 및 관리
- HTTPS(SSL) 적용 후 배포
